# Portfólio Victor & Iris

Portfólio colaborativo com foco em construção de universos, experimentos com IA e desenvolvimento web.

## Estrutura

- `/sobre` — quem somos nós e como trabalhamos juntos.
- `/sobre/victor` — perfil individual de Victor.
- `/sobre/iris` — perfil individual de Iris.
- `/o-que-fazemos/universos` — construção de universos.
- `/o-que-fazemos/ia` — experimentos com IA.
- `/o-que-fazemos/web` — desenvolvimento web.
- `/projetos` — projetos e colaboradores de cada trabalho.
- `/contato` — contatos individuais e contato para projetos em conjunto.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Observação

Os dados profissionais de cada pessoa ficam em `src/data/people.ts`. Os projetos ficam em `src/data/projects.ts` e listam apenas os nomes das pessoas que participaram de cada projeto.
